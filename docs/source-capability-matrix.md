## Findings and implementation choices

- Pararius robots was reviewed at `https://www.pararius.com/robots.txt` (last-updated line says 26 October 2026). Its explicit Amsterdam category exceptions allow the exact `/apartments/amsterdam/studio`, `/room`, and `/apartment` paths; listing-detail URLs are individually checked before any detail request. No internal API is used.
- Pararius's [terms of use](https://www.pararius.com/info/terms-of-use) describe a database right and restrict repeated/systematic request and reuse except where the personal-use exception applies. This installation is configured for one person's own housing search. It stores only search records for that use, sends them only to authorized Telegram users, and uses a 120-second minimum interval. If that personal-use basis does not apply to a particular use, disable the adapter and use platform notifications instead.
- Kamernet's [current terms](https://kamernet.nl/en/terms-conditions) explicitly prohibit automated access and systematic extraction. Its adapter is therefore disabled.
- Funda's [terms of use](https://www.funda.nl/en/voorwaarden-en-beleid/gebruiksvoorwaarden/) prohibit scraping/data mining without prior written permission. Its adapter is disabled until written permission is provided.
- HuurExpert's own [FAQ](https://www.huurexpert.nl/index/faq) says it aggregates listings from other sites, points to original sources, updates several times daily, and provides daily matching emails. Email alerts preserve its supported workflow and avoid recrawling its copied listing index.
- Van der Linden publishes its [rental listings](https://www.vanderlinden.nl/en/offer-rental-homes/) publicly; its [site terms](https://www.vanderlinden.nl/algemene-voorwaarden/) require responsible use. The adapter fails closed if robots cannot be read and keeps a five-minute interval.
- IamExpat publishes its [Amsterdam rental results](https://www.iamexpat.nl/housing/rental-properties/amsterdam); its [terms](https://www.iamexpat.nl/terms-of-use) say listings are provided by third parties and disclaim their accuracy. The adapter only stores public data and preserves the original listing link.
- VerhuurtBeter publishes a public [housing results page](https://www.verhuurtbeter.nl/en/housing) and warns users to use its official site for its listings. Its official pages are used, not paid third-party copies. The runtime robots check is fail-closed.
- Northflank and Oracle deployment characteristics are summarized in the README from their current [Northflank pricing](https://northflank.com/pricing), [Northflank billing documentation](https://northflank.com/docs/v1/application/billing/pricing-on-northflank), [Oracle Always Free resources](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm), and [Oracle idle instance rules](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm).

## Runtime interpretation

`ACTIVE` means an adapter recently completed a permitted search request. `DEGRADED` means the access check or request failed. `BLOCKED` means robots or access controls prevented the request. `UNSUPPORTED`, `DISABLED`, and `REQUIRES_AUTHENTICATION` are recorded as such and never counted as functioning sources. Mailbox intake is separate from scraping and requires the owner to configure the platform's official alert flow and a read-only mailbox.
